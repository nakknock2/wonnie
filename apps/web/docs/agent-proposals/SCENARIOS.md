# WONNIE 제안 시나리오 · 발표용 입력 예시

화면은 `scenarios.js`를 실행 데이터로 사용합니다. 아래는 시연자가 볼 수 있는 요약입니다. 모든 수치·상품 조건은 예시입니다.

| 시나리오 | 상황 / 비교 결과 | 첫 질문 예시 | 이어서 입력할 질문 |
|---|---|---|---|
| 이미 가진 카드의 혜택 활용 | Netflix 월 17,000원. 현재 할인 없음 → 보유 우리카드 A 월 5,000원 추가 할인. 연 60,000원 | 보유 카드 혜택 알려줘 | 얼마나 절약돼? → 혜택 조건 알려줘 → 결제 카드 바꾸는 방법 알려줘 |
| 새 우리카드와 순절약액 비교 | 월 구독 42,800원. 할인 1,000원 → 5,000원. 연 추가 할인 48,000원 − 추가 연회비 20,000원 = 순절약 28,000원 | 새 우리카드 추천해줘 | 연회비까지 비교해줘 → 실적 조건 알려줘 → 발급 전에 확인할 것 알려줘 |
| 구독료 인상 감지 | Netflix 지난달 14,900원 → 이번 달 17,000원. 차액 2,100원. 변화 이유는 미확인 | Netflix 결제 금액이 올랐어 | 지난 결제와 비교해줘 → 왜 오른 거야? → 확인 방법 알려줘 |
| 같은 서비스의 중복 결제 확인 | YouTube Premium 14,900원 결제 2건. 서로 다른 일자·카드. 불필요한 중복 여부는 미확인 | 중복 결제 확인해줘 | 두 결제 내역 보여줘 → 정말 중복이야? → 확인 방법 알려줘 |
| 더 저렴한 결제 경로 비교 | 가상 스트림플러스 동일 요금제. 앱마켓 17,000원 → 공식 직접 결제 15,500원. 월 차액 1,500원 | 결제 경로 비교해줘 | 같은 요금제 맞아? → 얼마나 절약돼? → 변경 방법 알려줘 |
| 이미 가진 멤버십의 포함 혜택 찾기 | 가상 라이프멤버십에 뮤직플러스 기본 이용권 포함. 같은 상품 별도 결제 7,900원. 기존 멤버십 유지 시 연 94,800원 차이 | 멤버십 포함 혜택 알려줘 | 포함 혜택 비교해줘 → 이용 조건 알려줘 → 연결 방법 알려줘 |

## 공통 대화 동작

- 추천 응답 버튼을 누르는 것과 같은 문장을 직접 입력하는 것은 같은 답변 분기로 이어집니다.
- “얼마나 절약돼?”는 현재 시나리오의 계산을, “왜 추천했어?”는 현재 제안의 판단 근거를 답합니다.
- 다른 시나리오의 키워드를 직접 입력하면 대화 중에도 해당 시나리오로 문맥이 전환됩니다.
- “다른 제안 보여줘”는 다음 무작위 제안을 표시합니다.
- “지금 방식 유지할게요”, “괜찮아요”는 현재 제안을 자동 추천에서 제외합니다.
- “중복 결제가 확실해?”는 확정할 수 없음을, “왜 금액이 올랐어?”는 원인이 확인되지 않았음을 설명합니다.
- “바꿔줘”, “해지해줘”, “발급해줘” 같은 표현은 실제 실행 대신 확인할 조건과 관리 방법을 안내합니다.
- 자유로운 모든 질문을 해석하는 AI는 아닙니다. 인식하지 못한 문장은 현재 제안에서 질문할 수 있는 내용을 안내합니다.
