# WONNIE 구독 절약 제안 시연

`index.html`을 더블클릭해 브라우저에서 여세요. 라이브 서버나 패키지 설치 없이 실행할 수 있습니다. 기존 1.chatting, 2.sub-list와 독립된 구현본입니다.

## 시연 방법

1. 첫 화면에는 절약 제안 6가지와 일정 기반 제안 3가지를 합친 아홉 제안 중 하나가 무작위로 표시됩니다.
2. 추천 응답을 누르거나 입력창에 직접 질문하면 제안에 맞는 답변과 비교 내역이 나타납니다.
3. 이후 “얼마나 절약돼?”, “왜 추천했어?”, “조건 알려줘”, “변경 방법 알려줘”처럼 이어서 질문할 수 있습니다.
4. `다른 제안 보기` 또는 `처음으로`를 누르면 대화를 정리하고 다음 무작위 시나리오로 전환합니다. 한 번의 순회에서는 아홉 시나리오가 중복 없이 나옵니다.
5. 상단 `시나리오` 또는 `시나리오 직접 선택`에서 발표할 상황을 바로 고를 수 있습니다.
6. “지금 방식 유지할게요”, “괜찮아요”처럼 답하면 해당 제안을 현재 실행 중 자동 추천에서 제외합니다. 직접 선택으로 다시 볼 수 있고, 페이지를 새로고침하면 초기화됩니다.
7. `캘린더 예시 일정 3건`을 누르면 시험·여행·마감 일정을 볼 수 있고, 각 일정에서 바로 제안 화면으로 이동할 수 있습니다. “내 일정 보여줘”, “시험 일정에 맞춰 제안해줘” 같은 직접 입력도 지원합니다. 실제 구글캘린더는 아직 연결하지 않습니다.

## 저장 구조

- `data/scenarios.js`: 실제 화면이 읽는 시나리오 원본. 제목, 제안 문구, 근거, 비교 수치, 추천 응답, 후속 답변과 전환 키워드를 보관합니다.
- `data/calendar-events.js`: 추후 구글캘린더 연동을 위한 예시 일정과 정기결제 데이터입니다. 날짜는 오늘의 한국 날짜를 기준으로 생성됩니다.
- `data/calendar-scenarios.js`: 예시 일정과 결제일을 읽어 시험·여행·마감 제안 및 후속 답변을 구성합니다.
- `data/SCENARIOS.md`: 아홉 시나리오별 발표 순서와 입력 예시 정리본입니다.
- `scenario-engine.js`: 무작위 순환, 문맥 유지, 질문 분류와 답변 선택 로직입니다.
- `app.js`: 첫 제안 카드와 채팅 화면, 비교표, 추천 응답, 시나리오 선택을 연결합니다.
- `styles.css`: 기존 WONNIE 스타일을 유지한 iPhone 17 Pro 크기의 모바일 레이아웃입니다.
- `assets/`: 이전 화면에서 사용한 WONNIE 캐릭터와 아이콘입니다.

실행 원본인 `data/scenarios.js`를 수정하면 화면에 반영됩니다. 질문 키워드를 추가하려면 각 시나리오의 `keywords`, 추천 응답을 바꾸려면 `prompts`, 후속 답변을 수정하려면 `replies`를 편집하세요.

## 구현 범위

서버나 실제 AI 모델을 호출하지 않는 시나리오 기반 프론트엔드입니다. 답변은 현재 대화 문맥과 입력 키워드로 선택되며, 준비된 제안·답변 문구 안에서 무작위로 표시됩니다. 준비되지 않은 질문은 가능한 질문을 안내합니다.

모든 금융 내역·카드·가격·멤버십 조건은 시연용 데이터입니다. 특히 비교용 우리카드 A/B/C, 스트림플러스, 라이프멤버십, 뮤직플러스는 실제 상품 안내로 사용하지 마세요. 실제 계좌·구독·사용 빈도·카드 실적을 조회하지 않으며 카드 발급, 결제 수단 변경, 해지, 잠금, 환불도 실행하지 않습니다.

보유 카드 절약액은 기존 카드 보유를 전제로 한 추가 할인입니다. 새 카드의 연 순절약액은 추가 할인에서 추가 연회비를 차감합니다. 결제 금액 변화와 서비스명 중복은 원인을 확인할 대상으로 표시하며, 자동으로 인상·불필요한 중복이라고 확정하지 않습니다.

마이크 입력은 브라우저의 음성 인식 지원과 권한에 따라 동작합니다. 입력 내용과 대화는 외부 AI 서버에 전송하지 않습니다. 브라우저 음성 인식 자체의 처리 방식은 사용 브라우저에 따릅니다.
