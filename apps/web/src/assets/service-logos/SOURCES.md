# Subscription service logo sources

The files in this directory are local UI references for identifying subscriptions. All brand marks remain trademarks of their respective owners.

- WATCHA: official [WATCHA brand logo and icon downloads](https://www.watchacorp.jp/e2e98e68-ae2e-4dc2-b9f2-03c16892eaec)
- Netflix: official [Netflix brand assets](https://brand.netflix.com/en/assets/logos/); compact SVG path sourced from [Simple Icons](https://simpleicons.org/)
- YouTube: official [YouTube brand resources](https://brand.youtube/); compact SVG path sourced from [Simple Icons](https://simpleicons.org/)
- Microsoft 365: [Microsoft trademark guidelines](https://www.microsoft.com/en-us/legal/intellectualproperty/trademarks) and the 2022 Microsoft 365 product mark
- TVING: the SVG currently served by the [official TVING website](https://www.tving.com/), checked against [CJ ENM's TVING identity announcement](https://www.cjenm.com/ko/news/%ED%8B%B0%EB%B9%99-%EB%B8%8C%EB%9E%9C%EB%93%9C-%EB%B9%84%EC%A3%BC%EC%96%BC-%EA%B0%9C%ED%8E%B8-%EB%B7%B0%EC%96%B4viewer%EC%97%90-%ED%8F%AC%EC%BB%A4%EC%8A%A4/)
- NAVER: official [NAVER brand resources](https://www.navercorp.com/company/brandGuide); compact SVG path sourced from [Simple Icons](https://simpleicons.org/)
- iCloud: [Apple intellectual-property guidance](https://www.apple.com/legal/intellectual-property/); compact SVG path sourced from [Simple Icons](https://simpleicons.org/)

Spotify, Netflix, YouTube, NAVER, and iCloud are rendered from the pinned `simple-icons` npm package. It provides normalized 24×24 paths; the UI adds a brand-specific safe area so marks are not clipped by the circular container.
