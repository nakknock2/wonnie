# 이전 마이그레이션 보관

V1~V4 원본을 변경하지 않고 보관한다. 이 디렉터리는 Flyway 실행 경로가 아니다.

현재 `docker` 프로파일은 `db/migration`의 새 V1/V2를, `local`은 같은 구조의 H2 변환본 `db/migration-h2`를 사용한다. 기존 DB의 V1~V4 이력과 새 V1/V2는 서로 다른 스키마이므로 기존 이력에 덮어쓰거나 `repair`/`baseline`으로 검증을 우회하면 안 된다.

Compose는 새 `mysql-data-v2` 볼륨을 사용한다. 이전 기본 볼륨 `infra_mysql-data`는 삭제하지 않는다. 이전 데이터는 자동 이관하지 않으며, 필요하면 구버전 코드/이 디렉터리의 마이그레이션과 기존 볼륨을 사용해 별도 복구·이관한다.
