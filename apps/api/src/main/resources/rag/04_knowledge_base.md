# 04. 워니 지식 문서 (Knowledge Base)

> RAG로 검색·조회해서 `knowledge`에 붙이는 문서. 각 섹션은 `[KEY]`로 시작하고 `---`로 나뉜다.
> 섹션 KEY는 DB의 `service.rag_doc_key`, `card_product.rag_doc_key`와 같다 → 백엔드가 KEY로 바로 찾아 붙일 수 있다.
> 모든 내용은 **해커톤 시연용 요약**이다. 서비스 메뉴 이름·카드 혜택은 바뀔 수 있으니 발표 전 최신 정보를 확인한다.

## [KB-MERCHANT-DECODE] 결제명으로 서비스를 알 수 없는 경우

카드 승인 내역의 가맹점명만으로는 어떤 서비스인지 알 수 없는 경우가 있다. 이때 워니는 **추측하지 않고 고객에게 묻는다** (순간 M-R02-S).

| 가맹점명 예시 | 의미 | 워니가 하는 일 |
| --- | --- | --- |
| `APPLE.COM/BILL` | 아이폰·아이패드에서 애플 결제로 가입한 구독. 여러 앱 구독이 이 이름으로 찍힌다 | "어떤 앱인지" 묻고, 모르면 KB-HOWTO-APPLE 안내 |
| `GOOGLE*` 로 시작 | 구글플레이 결제. 뒤에 서비스명이 붙으면 그 서비스 | 서비스명이 있으면 매핑, 없으면 묻기 + KB-HOWTO-GOOGLE |
| `네이버페이`, `카카오페이`, `토스페이` | 간편결제를 거친 결제. 안의 가맹점이 안 보인다 | 정기 패턴이면 묻기 |
| 결제대행사(PG) 이름 | 토스페이먼츠, KG이니시스, NHN KCP 등을 거친 결제 | 정기 패턴이면 묻기 |

## [KB-HOWTO-APPLE] 애플 구독 확인·해지 방법

- 아이폰 **설정 > (맨 위) 내 이름 > 구독**에서 애플 결제로 가입한 구독 목록을 볼 수 있다.
- 해지도 같은 화면에서 구독을 눌러 **구독 취소**로 한다.
- 애플 결제 구독은 서비스 앱·웹이 아니라 애플에서 해지해야 한다.
- 워니는 해지를 대신 하지 않는다. 이 경로를 안내한다.

## [KB-HOWTO-GOOGLE] 구글플레이 구독 확인·해지 방법

- **Play 스토어 앱 > 프로필 > 결제 및 정기 결제 > 정기 결제**에서 구독 목록을 볼 수 있다.
- 해지는 구독을 눌러 **정기 결제 취소**로 한다.
- 일부 앱은 구글플레이의 **결제 일시중지** 기능을 지원한다 (앱마다 다름).

## [SVC-WATCHA] 왓챠

- **분류**: OTT (영화·드라마)
- **결제 경로**: 웹 결제가 일반적. 앱스토어로 가입했다면 KB-HOWTO-APPLE / KB-HOWTO-GOOGLE

## [CARD-ROUTINE] 카드의정석2 ROUTINE (우리카드)

- **혜택**: 디지털 구독 서비스·멤버십 **30% 할인** · 아파트관리비·공과금·이동통신·교육·도서·렌탈 15% 할인 · 해외 온·오프라인 1.5% 할인
- **조건**: 전월실적 **50만 원 이상** → 할인 영역별 **월 최대 5,000원** (월 최대 3만 원) / 전월실적 **100만 원 이상** → 영역별 최대 1만 원 (월 최대 6만 원)
- **기타**: 아파트관리비도 전월실적에 포함 · 간편결제(우리WON페이·네이버페이·카카오페이) 5만 원 이상 결제 시 1,000원 할인 (월 3회)
- **출시**: 2026년 5월
- **주의**: 할인 대상 구독 서비스 세부 목록은 실제 약관 확인 필요. 워니는 혜택을 말할 때 **조건(전월실적·한도)을 함께** 말한다

## [PRODUCT-WONNIE-SAVING] 워니 절약 적금 (서비스 전용 · 모의 상품)

- 워니 서비스 **전용 적금**이다. 다른 적금 계좌에 넣는 선택지는 없다.
- **해커톤 시연용 가상 상품**이다. 실제 금리·약관이 없다. 고객에게 금리를 말하지 않는다. 시뮬레이션은 "원금 기준".
- **개설**: 처음 [워니 절약 적금에 쌓기]를 누를 때 앱이 개설한다 (우리은행 정보 제공 동의 1회). 그 전 상태는 `NOT_OPENED`.
- **쌓는 방식**:
  - 월 구독 해지·요금제 하향·묶음 정리 → **원래 결제일마다 같은 금액** 자동 적립 (첫 회는 바로)
  - 연간 구독 해지 → 한 번에, 또는 12번 나눠서
  - 카드 할인 확정액 → 이번 한 번
- **잔액 부족**: 같은 날 다른 결제가 있으면 하루 미루고, 그래도 부족하면 그 달은 건너뛴다. 연체·독촉이 아니다.
- **멈추기**: 언제든 멈출 수 있다. 해지했던 구독을 다시 시작하면 워니가 멈출지 묻는다.
- **목표**: 기본 첫 목표 100,000원. 캘린더 여행 등과 연결하면 "여행까지 얼마"로 보여준다.
- **워니 성장**: 누적액이 늘면 새싹 워니가 단계별로 자란다.

## [POINT-KKULMONEY] 꿀머니

- 우리금융 통합 멤버십(우리WON멤버스)의 포인트.
- **꿀머니로 받기 (워니 선택지)**: 아낀 금액만큼 WON 통장에서 꿀머니로 바꿔 받고, **추가 꿀머니**를 얹어 받는다. 주기는 적금과 같다 (월 구독이면 원래 결제일마다). 추가 꿀머니 금액은 컨텍스트(`facts.simulation.bonus_point`)에 있을 때만 말한다.
- 적금과의 차이: 적금은 모아두는 돈, 꿀머니는 가맹점에서 바로 쓰는 포인트.
- **소멸 예정 꿀머니**가 있으면 알려줄 수 있다 (M-R07-C5, M-R12-C5).
- **주의**: 꿀머니로 구독료를 낼 수 있는지는 확인되지 않았다. "쓸 수 있는지 볼까요?"처럼 말한다.

## [REG-DARKPATTERN] 구독 결제 관련 소비자 보호 규정 (2025년 2월~)

- 전자상거래법 시행령 개정으로, 사업자는 **무료체험이 유료로 바뀔 때**와 **정기결제 가격을 올릴 때** 소비자의 **별도 동의**를 받아야 한다.
- 해지를 가입보다 어렵게 만들거나, 해지 방법을 제한하는 것은 금지된다.
- 워니가 쓰는 법: 가격 인상(M-R05-S)이나 무료체험 전환(M-R04-S)에서 고객이 "몰랐다"고 하면 "가격 인상이나 유료 전환 전에는 따로 동의를 받게 되어 있어요. 서비스 고객센터에 확인해 보세요"라고 안내할 수 있다. 법률 판단은 하지 않는다.

## [REG-DATA-USE] 워니가 쓰는 데이터와 쓰지 않는 데이터

- **누가**: 워니는 **우리카드가 제공하는 서비스**로, 그룹 통합 앱 우리WON뱅킹 안에서 동작한다.
- **쓰는 것**: 우리카드 결제내역·청구서, 보유 카드·혜택·이용실적·카드 상태, 꿀머니, 카드 신청 때 받은 기본 정보(나이·거주지·직업·소득 구간), 고객이 동의한 구글 캘린더 일정 신호, 고객이 워니에게 한 답
- **쓰지 않는 것**: 성별, 서비스 시청·사용 기록(카드사는 알 수 없음), 캘린더 일정 원문, 동의하지 않은 데이터
- **우리은행 계좌·워니 절약 적금**: 고객이 [워니 절약 적금에 쌓기]를 고르는 순간 따로 동의를 받은 뒤에만 쓴다 (계열사 간 정보 공유 규정)

| 질문 | 워니의 답 (요지) |
| --- | --- |
| 워니가 결제를 막아 줄 수 있어? | 아니요. 결제를 막거나 해지를 대신 하지는 않아요. 해지할 수 있는 곳으로 바로 안내해 드려요. |
| 내가 넷플릭스 얼마나 보는지 알아? | 아니요, 워니는 시청 기록을 몰라요. 대신 결제 전에 계속 볼지 여쭤봐요. |
| 내 정보 어디에 써? | 구독을 찾고, 결제 전에 알려드리고, 아낀 돈을 정리하는 데만 써요. (REG-DATA-USE) |
| 캘린더에 마음대로 일정 넣는 거 아니야? | 아니요. 넣기 전에 항상 미리보기를 보여드리고, [등록]을 누르셔야 들어가요. 워니 전용 캘린더에만 넣어요. |
| 적금 이체 진짜야? | 지금은 시연용 모의 이체예요. 실제 돈은 움직이지 않아요. |
| 적금이랑 꿀머니 뭐가 달라? | 적금은 모아두는 돈이고, 꿀머니는 가맹점에서 바로 쓰는 포인트예요. 아낀 금액만큼 꿀머니로 받으면 추가 꿀머니도 얹어 드려요. |
| 다른 적금에 넣을 수 있어? | 아낀 돈은 워니 전용 '워니 절약 적금'에 쌓여요. |
| 매달 쌓는 거 멈추고 싶어 | 언제든 멈출 수 있어요. (PAUSE_SAVING_PLAN 버튼) |
| 쌓기 싫으면? | [안 할래요]를 고르시면 쌓지 않고 누적 절약액에만 기록해요. |
| 알림이 너무 많아 | 원하시는 종류의 알림을 끌 수 있어요. (MUTE_THIS_ROW 버튼) |
| 동의 취소하고 싶어 | 설정에서 언제든 동의를 철회할 수 있어요. |
| 이 카드 발급될까? | 조건에 맞을 수 있어요. 정확한 발급 여부는 심사 후 결정돼요. |
| 주식·투자 추천해 줘 | 워니는 구독·결제 절약을 돕는 친구라 투자 추천은 하지 않아요. |
