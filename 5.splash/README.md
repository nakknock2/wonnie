# WONNIE 스플래시 프론트

`index.html` 또는 `preview.html`을 더블클릭해 실행합니다. 별도 설치나 라이브 서버가 필요 없습니다.

- 원본 사진의 행사 로고·색상 장식·접근성 표기·우리은행 로고를 SVG의 viewBox로 해당 영역만 표시합니다. 원본 로고를 다른 글꼴로 대체하지 않았습니다.
- 흰 화면, 안내 문구, 배치, 홈 인디케이터는 HTML/CSS이며 워니는 독립 투명 PNG입니다.
- 사진의 바깥 테두리는 휴대폰 화면이 아니므로 앱 내부에 넣지 않았습니다. PC에서는 둥근 미리보기, 모바일에서는 전체 화면으로 표시합니다.
- 402 × 874 기준 비율이며 다양한 화면 너비에서도 비율을 맞춥니다.
- 스플래시 화면만 표시합니다. 클릭·키보드·시간 경과에 따른 화면 이동은 없습니다. 홈 화면 연결은 팀원이 담당합니다.
- `styles.css`에서 `.wonnie`의 위치·크기, `.campaign-message`에서 문구 스타일을 수정합니다.
- `preview.html`은 CSS·이미지를 포함한 단일 파일입니다. 소스 수정 후 함께 갱신해야 합니다.

원본 사진에 있던 인증 표기를 디자인 참고용으로 표시하며, 이 시연 화면 자체가 접근성 인증을 받았다는 의미는 아닙니다.

소스 수정 후 단일 파일 갱신: node build-preview.cjs

워니 위치: left: 39%. splash.js는 실행하지 않는 안내 파일입니다.
